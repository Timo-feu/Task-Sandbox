# Task-Sandbox
Легкая очередь задач для ИИ модели работающая в многопотоке.
Вам нужно приложение, которое могло бы вревратить локальную ии модель в агента, который может выполнять ваши задачи друг-за другом без остановки, коммитить изменения и это все не в сухой командной строке, а в обретке из красивого графического интерфейса? 
### Тогда вам нужен Task-Sandbox!
